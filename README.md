# proyecto-8-salud-analytic

 Análisis de Clínica - Sector Salud

Base de datos y dashboard BI para análisis de turnos, 
facturación y productividad médica.

## Tecnologías
- SQL Server
- Power BI Desktop (DAX)

## Contenido
- `salud_analytics.sql` — 5 tablas, 2 views y consultas de análisis
- `dashboard-salud.pbix` — Dashboard de 2 páginas: Resumen Clínica y Facturación

## Consultas destacadas
- Tasa de asistencia por especialidad
- Facturación por obra social
- Ranking de médicos por productividad
